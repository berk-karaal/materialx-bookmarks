# About this demo

This site is built from the `demo/` directory of the
[materialx-bookmarks](https://github.com/berk-karaal/materialx-bookmarks) repository, using the
plugin from the same commit. It exists so the component can be exercised in a real
mkdocs-materialx build rather than only in tests.

The page you are reading holds no bookmark component, which makes it a useful starting point when
checking that the component still initialises after navigating from a page that never loaded it.
